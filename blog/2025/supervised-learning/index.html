Supervised learning is one of the fundamental paradigms of machine learning. In essence, it consists of training a model using labeled data, that is, data in which both the inputs (features) and the correct outputs (labels or targets) are known. The model learns to map inputs to outputs by identifying patterns and relationships in the data.

This process resembles a student learning under the supervision of a teacher: the model is presented with examples and their correct answers, and learns to generalize in order to correctly predict new inputs.

How does it work?

Supervised learning operates with a labeled dataset, where each ‘point’ of information includes an input (the features) and its expected output (the label). The objective of the model is to learn a mapping — a mathematical function — that transforms those inputs into the correct outputs. Thus, when the model sees new inputs it has never seen before, it will be able to predict their output with high accuracy.

Phases of Supervised Learning

Training Phase

The model receives many input-output pairs. It learns a function that approximates the relationship between them.

Prediction Phase

Once trained, the model receives new inputs (without labels) and generates predictions based on what it has learned.

The data is usually divided into:

  • Training Set (70–80%): To learn the patterns.
  • Validation Set (10–15%): To adjust hyperparameters.
  • Test Set (10–15%): To evaluate the final performance of the model.

Key Concepts

  • Input Features (Features/X): Attributes used by the model to make predictions.
  • Labels (Labels/Targets/y): Expected results the model must learn to predict.
  • Loss Function (missing term): Error between predictions and the actual labels.
  • Generalization: The model’s ability to make correct predictions on new data.

Types of Supervised Learning

Classification

The model predicts discrete categories.

Regression

The model predicts continuous numerical values.

Structured Prediction

The model predicts complex outputs, such as sequences or structures.

Challenges of Supervised Learning

Overfitting:

The model learns the training data too well, memorizing the “noise” instead of the general patterns.

Underfitting:

The model is too simple to capture relevant patterns in the dataset. It fails to learn adequately from both training and new data.
